Importar productos

Paso 1 · Descargar plantilla

Completá la plantilla en Excel, LibreOffice o Google Sheets y luego subila en el paso 2. La columna imagen puede ser el nombre de un archivo dentro del ZIP del paso 3 (ej. JW-BLACK-750.jpg) o una URL https://.... Si la dejás vacía, se busca automáticamente una imagen con el mismo nombre que el codigo, y si tampoco existe se puede buscar en internet (paso 3). Columna opcional barcode (o gtin): si tenés el código de barras/EAN/UPC del producto, mejora mucho la precisión de esa búsqueda automática — no reemplaza a codigo (que sigue siendo el identificador interno) y no rompe archivos que no la incluyan.

Paso 2 · Seleccionar productos

Arrastrá tu archivo aquí o hacé clic para elegirlo

.csv o .xlsx — máximo 10 MB, 2000 filas

Paso 3 · Imágenes de productos

Si un producto no tiene imagen, Don Víctor intentará encontrarla automáticamente utilizando su código, marca, nombre y presentación. Las imágenes encontradas se revisan antes de importar — nunca se asignan a ciegas.

O subí un ZIP de imágenes (opcional)

Arrastrá tu ZIP aquí o hacé clic para elegirlo

.zip — máximo 60 MB, 1000 archivos

Orden de prioridad para la imagen de cada producto: URL en la columna imagen → archivo indicado en el ZIP → archivo en el ZIP que coincide con el codigo → búsqueda automática (si está activada) → sin imagen.

Productos existentes (por código)

Un producto se considera existente cuando su codigo ya está en la base de datos. Filas sin código nunca actualizan un producto existente: siempre se crean como nuevos.

Apagado por defecto: si un producto existente ya tiene imagen, ni el ZIP ni la búsqueda automática la van a reemplazar salvo que actives esta opción.
